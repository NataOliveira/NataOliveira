## 👨‍💻 Sobre mim

Sou desenvolvedor em formação focado no ecossistema **Python**, com sólida base em **Programação Orientada a Objetos (POO)**, desenvolvimento de aplicações desktop e persistência em bancos de dados relacionais. Gosto de construir projetos reais combinando lógica robusta no backend com interfaces modernas, responsivas e elegantes no front-end.

- 🎮 Atualmente desenvolvendo um **RPG em texto** com hierarquia de classes (heróis, mobs e boss), sistema de batalha e inventário baseado em POO e JSON.
- 🏦 Construí o **Dreyfus Bank**, um sistema desktop de login/cadastro robusto utilizando CustomTkinter, persistência com PostgreSQL e segurança avançada (hashing de senhas com bcrypt).
- 🎨 Desenvolvendo meu **Portfólio Pessoal (DreyfusDev)** utilizando HTML5, CSS3 (Flexbox, Media Queries), JavaScript e integração 3D via Spline, focando em design responsivo e estética moderna (Glassmorphism).
- 🌱 Sempre aperfeiçoando: herança, polimorfismo, encapsulamento, `@property`, modelagem de dados SQL, padrões de arquitetura e boas práticas de código limpo.
